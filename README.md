## 使用建议

1. 先读知识大纲 §1 建立全局地图；
2. 按章读复习资料的“主线 → 精讲 → 例题”；
3. 遮住答案做每章“自测”，错题回到精讲；
4. 考前只看每章“速记卡”和易错点。
